# 2026-10-02

## AirPlus 构建系统迁移：ForgeGradle → Architectury Loom + Kotlin DSL
- 构建后端由 ForgeGradle(旧版)+mixingradle 替换为 **gg.essential.loom 0.10.0.+**（基于 lineargraph/Forge1.8.9Template，本质是 Architectury Loom 而非 ForgeGradle）。
- 构建脚本 Groovy → Kotlin DSL：新建 `build.gradle.kts` / `settings.gradle.kts`，删除旧 `build.gradle` / `settings.gradle`。
- `gradle.properties`：新增 `loom.platform=forge`、`baseGroup=net.airplus`、`mcVersion=1.8.9`、`modid=airplus`、`version=1.0`；移除 `forgegradle_version`/`mixingradle_version`/`mod_version`/`maven_group`/`archives_base_name`。
- `gradle-wrapper.properties`：`distributionUrl` → `gradle-8.10.2`（wrapper jar 尚未更新，需本地联网后 `gradlew wrapper` 更新）。
- 新增 `log4j2.xml`（loom `log4jConfigs` 引用）。
- 精简 `MixinLoader.java`（`IFMLLoadingPlugin` CoreMod）：删除 `MixinBootstrap.init()/addConfiguration()/setSide`，仅保留 `getASMTransformerClass()` 挂 `ForgeNetworkTransformer` + `AbstractJavaLinkerTransformer`。原因：`AbstractJavaLinkerTransformer` 改写 JDK 内部类 `jdk.internal.dynalink.beans.AbstractJavaLinker`，Mixin 无法触及，只能 CoreMod/IClassTransformer 链；故保留 CoreMod 仅作 transformer 载体。
- 产物流程：`remapJar`（取代 ForgeGradle 的 `reobf`）从 `shadowJar` 重新映射，最终 `build/libs/airplus-1.0.jar`。
- manifest 保留 `FMLCorePlugin`(MixinLoader) / `TweakClass`(MixinTweaker) / `MixinConfigs` / `FMLAT`。
- **未完成构建验证**：本沙箱无外网（`gradlew` 下载 gradle-8.10.2 时 Connection timed out），且无法下载 Loom/MC/Forge/依赖。本机默认 JDK 21 满足 Gradle 8 运行要求。
- 关键风险（待本地实测）：Loom forge 平台是否仍扫描并加载第三方 `FMLCorePlugin` CoreMod 不确定；若不加载，则 `ForgeNetworkTransformer` 需改 Mixin(target FML 类)，`AbstractJavaLinkerTransformer` 需改用 Loom forge 的 coremods JSON 机制或放弃该 nashorn 链接增强。
